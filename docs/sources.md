# 출처 확인

공식 공개 페이지를 2026-10-04에 확인했습니다. 로그인, 키 발급, 실제 서비스키 조회나 API 호출은 하지 않았습니다. 현재 산출물의 사건 데이터는 직접 만든 예제뿐입니다.

| 대상 | 공식 출처 | 공개 조건 | 후보에서 사용하는 기능 |
|---|---|---|---|
| 기상특보 | [기상청 기상특보 조회서비스](https://www.data.go.kr/data/15000415/openapi.do) | 공공누리 제1유형, 출처 표시 | `getWthrWrnList`, 제목과 발표 기록 |
| 지진 | [기상청 지진정보 조회서비스](https://www.data.go.kr/data/15000420/openapi.do) | 이용허락범위 제한 없음 | `getEqkMsg`, 발생 및 발표 기록 |

[공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do)은 출처를 표시한 공유, 변경, 영리 이용을 허용합니다. JSON은 제공기관, 데이터 이름, 출처 링크와 확인 날짜를 항상 포함합니다. 실제 자료를 표시할 때 그 출처와 원본 발표 시각도 함께 표시해야 합니다. 정부의 후원이나 공식 서비스로 오인할 표현을 쓰지 않습니다.

특보 목록에서 공식 페이지로 확인한 필드는 `title`, `stnId`, `tmSeq`, `tmFc`입니다. 지진은 `tmFc`, `tmEqk`, `lat`, `lon`, `loc`, `mt`, `inT`, `cor`를 사용합니다. 이미지와 불필요한 참고 문구, 알 수 없는 추가 필드는 공개하지 않습니다. 페이지별 결과 수와 전체 수를 확인한 뒤에만 성공으로 처리합니다.

두 서비스의 공식 요청변수 표에 따라 인증키 파라미터 이름은 대소문자를 포함해 `ServiceKey`를 사용합니다. 인공 키 문자열로 두 요청의 이름과 URL 인코딩을 시험했으며 실제 인증 성공을 확인한 것은 아닙니다. 원본 기록의 수정과 삭제 방식도 실서비스 검증 전입니다.

목록의 발표 시각은 현재 지역의 활성 상태를 보장하지 않습니다. 특보현황과 적용, 해제의 구조는 현재 접근 가능한 공식 상세 페이지만으로 충분히 확인하지 못했습니다. 공개 활용가이드의 다운로드도 이 작업 환경에서 열리지 않았습니다. 실제 키로 문서, 응답 형태와 페이지 규칙을 확인하기 전에는 `LIVE_API_VERIFIED`를 켜지 않습니다. 재배포 조건을 새로 해석하거나 웹 화면을 긁어 이 빈틈을 채우지 않았습니다.

재난문자, 민방위 경보, 홍수, 대기질, 응급실 병상, 시설이나 지도 자료는 수집하지 않습니다. 이번 두 출처 외의 이용 조건이 불명확한 자료는 공개 산출물에 넣지 않았습니다.

R2는 [공개 버킷과 자체 도메인](https://developers.cloudflare.com/r2/buckets/public-buckets/) 및 [S3 호환 API](https://developers.cloudflare.com/r2/api/s3/api/)를 확인했습니다. R2의 GET, PUT과 조건부 갱신을 사용하며, 별도 사용자 API 서버는 만들지 않습니다. [공식 연결 예제](https://developers.cloudflare.com/r2/examples/aws/aws-sdk-go/)의 계정별 HTTPS 엔드포인트와 `auto` 리전을 따릅니다.

Pages는 [이용 한도와 상업 서비스 제한](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) 및 [추가 제품 약관](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features)을 확인했습니다. 공식 Pages 제한은 상업 거래나 상업 SaaS 제공을 주된 목적으로 하는 무료 호스팅에 적용됩니다. 상업 앱과 관련된 모든 정적 JSON을 금지한다고 명시한 것은 아닙니다. 이 후보의 실제 이용 목적과 예상 사용량이 그 제한에 해당하는지는 아직 판단하지 않았습니다. Pages를 선택할지와 공개 승인은 소유자의 결정입니다.

Pages의 공개 사이트 크기 한도는 1 GB이며 월 대역폭은 100 GB의 소프트 한도입니다. 별도 Actions 작업으로 배포하는 경우에는 시간당 10회 빌드 소프트 한도가 적용되지 않습니다. Actions는 CDN이나 무관한 상시 서버 용도로 쓸 수 없고 과도한 부담을 주어서는 안 됩니다. 프로젝트 자료 수집과 배포가 실제 목적과 사용량에 맞는지 운영 전에 확인해야 합니다. 취약 의존성에 따른 현재 실행 잠금은 이 약관 검토와 별개입니다.
