# 기상특보와 지진 조회용 정적 중계 후보 추가

Refs #<issue-number>

키를 공개 산출물에 넣지 않고 두 공식 데이터 서비스의 발표 기록을 JSON으로 중계합니다. 일부 조회가 실패하거나 HTTP 200에 오래된 자료가 담겨도 마지막 유효 자료와 성공 시각을 유지하며 실패를 빈 성공 목록으로 덮어쓰지 않습니다.

실제 조회 전과 직접 만든 예제를 분리했습니다. 현재 특보 목록에서는 활성, 적용, 해제 상태를 추측하지 않고 특보 없음 표시를 하지 않습니다. 지진 발생과 발표 시각도 분리합니다. 정부 경보 수신이나 푸시, 자동 상황 선택에는 연결하지 않습니다.

최신 발표 시각이 유지되면 오래된 일부 기록이 누락된 응답도 새 목록으로 교체하는 현재 동작을 테스트로 명시했습니다. 같은 조회 범위의 모든 기록을 보존한다고 설명하지 않으며, 실제 API의 수정과 삭제 방식은 검증 전입니다. 인증 파라미터는 두 공식 요청변수 표의 `ServiceKey` 표기를 따릅니다. 로컬 파일의 원자적 교체가 부모 경로의 링크까지 차단하는 것은 아니라는 범위도 문서에 적었습니다.

R2는 마지막 객체를 읽은 뒤 ETag 조건부 PUT 하나로 갱신합니다. CI와 R2 경로는 외부 checkout Action 대신 고정 공개 저장소의 ref와 SHA를 확인하는 네이티브 Git을 사용합니다. Pages 대체 구성은 같은 자료 계약으로 준비했지만 의존성 검사에서 알려진 취약점이 발견되어 코드에서 잠갔습니다. 승인 변수만으로 실행되지 않습니다. 실제 계정, 키와 배포 시험은 남아 있습니다.

로컬에서 키 없는 단위 테스트, 예제와 미조회 JSON 생성, Pages 산출물 생성, 파일 및 Git 기록 검사 기능을 실행했습니다. 실제 결과와 공개 파일의 해시 목록은 공개 전 별도 검토 기록으로 확인합니다. 실서비스와 Actions 원격 실행을 시험한 것으로 주장하지 않습니다.

소스 코드 라이선스, 현황 API의 공식 정의와 실제 응답, R2 계정과 도메인, Pages 이용 적합성 확인이 남아 있습니다. 이 초안은 원격 PR이 아니며 이슈 생성 후 위 번호 자리 표시를 실제 번호로 바꿔 draft로 제출합니다.
